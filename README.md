# ThinkBot – AI Chatbot Website

ThinkBot is an AI chatbot website project made to give an interactive and easy to use chatting experience. It has a look and a design that works on all devices which makes it a good front-end development portfolio project.

## Live Demo

Try ThinkBot: https://rizwan-bm.github.io/ThinkBot/

## Features

- Chat with the chatbot

- Make the user interface look attractive

- Add animated dark theme

- Make the layout work on all device sizes

- Add smooth animations and transitions

- Make the chat area clean and easy to use

## Technologies Used

- HTML5 – For the website structure

- CSS3 – For the styling, animations and responsive design

- JavaScript – For the chat interface interactions

## Preview

Go to the demo to see the ThinkBot interface and the design.

Link: https://rizwan-bm.github.io/ThinkBot/

## Getting Started

Do these steps to run the project on your computer.

1. Copy the repository:

```bash

git clone https://github.com/rizwan-bm/ThinkBot.git

```

2. Open the project folder in Visual Studio Code.

3. Open index.html in your browser. Use the Live Server extension.

## Project Objective

The goal of ThinkBot is to show front-end development skills using a chatbot interface modern web design and responsive layouts.

Note: Actual AI responses need an AI backend or API. The functionality depends on how the project's built.
